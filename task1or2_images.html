Task 1 & 2 — HTML Images

src · alt · width · height · External URL · Same Folder · Another Folder

A — Image from an External Website URL

The src attribute here points to a fully qualified https:// URL hosted on another server. The alt text is shown if the image cannot load.

B — Image from the Same Folder

When the image file lives in the same directory as this HTML file, just use the filename as the src. Place flower.jpg (or any image) next to this file.

C — Image from Another Folder in the Project

Use a relative path with the folder name to reach an image stored in a sub-directory of your project. Create a folder called images/ and place landscape.jpg inside it.

D — Image Attributes Explained

Every <img> tag supports the following core attributes:

Attribute Purpose Example Value
src Specifies the path or URL of the image file (required) images/photo.jpg
alt Alternative text shown when image fails to load; also used by screen readers for accessibility A mountain sunset
width Sets the display width of the image in pixels 300
height Sets the display height of the image in pixels 200
