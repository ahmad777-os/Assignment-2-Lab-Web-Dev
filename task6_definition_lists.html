Task 6

Definition Lists

Using <dl>, <dt>, and <dd> elements

Three elements work together:  <dl> — the Definition List container  |  <dt> — Definition Term (the word/phrase)  |  <dd> — Definition Description (the explanation)
<dl> Definition List <dt> Definition Term <dd> Definition Description

Example 1 — Programming Glossary

Programming Terms — <dl> with <dt> & <dd>
HTML
HyperText Markup Language — the standard language used to create and structure web pages using elements and tags.
CSS
Cascading Style Sheets — a stylesheet language used to control the visual presentation and layout of HTML documents.
JavaScript
A lightweight, interpreted programming language that enables dynamic, interactive behaviour on web pages and in servers.
PHP
PHP: Hypertext Preprocessor — a widely-used open source server-side scripting language designed for web development.
MySQL
An open-source relational database management system based on Structured Query Language (SQL).

Example 2 — Computer Science Concepts

CS Concepts — multiple <dd> per <dt>
Algorithm
A step-by-step procedure for solving a problem or accomplishing a task.
Examples: Bubble Sort, Binary Search, Dijkstra's shortest path.
Data Structure
A way of organising and storing data so it can be accessed and modified efficiently.
Common types: Arrays, Linked Lists, Stacks, Queues, Trees, Graphs.
Recursion
A technique where a function calls itself in order to solve a problem by breaking it into smaller sub-problems.
Abstraction
Hiding complex implementation details and showing only the essential features of an object or system.

Example 3 — Web Server Glossary

WAMP / XAMPP Terminology
WAMP
Windows, Apache, MySQL, PHP — a local web server stack for Windows that lets developers build and test web applications offline.
XAMPP
Cross-platform Apache, MariaDB, PHP, Perl — a free, open-source local server environment available for Windows, Linux, and macOS.
Apache
A free, open-source HTTP web server software that serves web pages over the internet or a local network.
localhost
A hostname that refers to the current computer. Used to access web servers running locally via the browser (127.0.0.1).
Virtual Host
A configuration that allows a single Apache server to host multiple websites or domains on one machine.

Example 4 — HTML Tags Quick Reference

Common HTML Elements Defined
<head>
Contains metadata about the document such as title, charset, styles, and links to external resources. Not displayed in the browser.
<body>
Contains all the visible content of the webpage including text, images, lists, links, and other HTML elements.
<img>
Embeds an image in a webpage. It is a void element and requires the src attribute to specify the image path.
<ol> / <ul>
<ol> creates an ordered (numbered) list while <ul> creates an unordered (bulleted) list. Both contain <li> items.
<dl>
Creates a description/definition list. Must contain pairs of <dt> (term) and <dd> (description) elements.
